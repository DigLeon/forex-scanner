# v5.3.2 — Auto Scan Startup Fix

## Problem
Auto Scan stayed disabled after a Node.js server restart until `/api/scan` was called manually from the GUI.

## Fix
- Auto Scan is enabled automatically inside the `app.listen()` startup callback.
- First automatic scan runs after a short startup delay (default 2500 ms).
- Existing recurring cadence remains 10 minutes minimum.
- Existing `scanInProgress` guard remains active.
- Existing session-off/API guards remain active.
- Manual SCAN NOW still works and can update the Auto Scan query parameters.

## Optional environment variable
`AUTO_SCAN_STARTUP_DELAY_MS=2500`

## Expected startup log
`[AUTO SCAN] enabled on server startup | first scan in 3 sec | interval: 10 min`
then
`[AUTO SCAN] startup starting | next cycle interval: 10 min`

## Unchanged
No changes to Score, Entry Engine, Expiration Engine, Telegram dedupe, WAIT research statistics, Targeted Freshness Rescue, or API credit limits.
