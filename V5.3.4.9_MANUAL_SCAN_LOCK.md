# v5.3.4.9 — Independent Manual Scan Lock

Manual Analysis no longer shares the global full-scan lock.

- Auto Scanner may continue in the background.
- Manual Analysis can scan a selected pair at the same time.
- Duplicate manual scans of the same pair are blocked until that pair finishes.
- Different manual pairs are not blocked by each other.
- Core scoring, entry, expiration, Telegram, and research logic are unchanged.
