# v4.9.6 Score Diagnostics

Instrumentation-only release. Trading/filter thresholds are unchanged.

Every analyzed pair is now written to:
`score-diagnostics-history.jsonl`

Each row records:
- timestamp and price
- Context / Setup directions
- selected Context / Setup / Entry / Strategy / Session component scores
- bullish and bearish component scores
- raw UP/DOWN score
- quality adjustment and regime penalty
- final UP/DOWN scores
- edge and required score/edge
- Candidate/WAIT state
- Entry Zone status and prices
- Signal Strength
- Candle Confirmation
- blockers

Console now prints one compact `[SCORE TRACE]` line per pair.

API:
- `GET /api/score-diagnostics?limit=100`
- `GET /api/score-diagnostics?symbol=EUR/JPY&limit=50`
- `POST /api/score-diagnostics/clear`

The logger keeps up to 5000 rows.

No TRADE thresholds or hard blockers were weakened in this release.
