# Forex Scanner v4.8 — Unified Score Filter

Visible GUI changes:
- Removed Score Weight Equalizer from the interface.
- Removed Aggressive/Balanced/Conservative/Custom presets from the interface.
- Removed Minimum Signal Score dropdown from the interface.
- Removed WATCH 40+ checkbox from the interface.
- Added one Signal Score Filter slider from 0 to 100.

How it works:
- The audited score formula stays fixed at 20/30/25/15/10.
- Pair safety minimums stay unchanged and still protect TRADE decisions.
- The server also returns directional CANDIDATE rows that did not reach the pair safety score but still have sufficient directional edge.
- The 0..100 slider filters TRADE / WAIT / CANDIDATE rows by calculated Score.
- CANDIDATE never becomes TRADE and has no expiration/entry permission.

Examples:
Filter 0  -> show all scored directional rows that have sufficient edge.
Filter 40 -> show score >= 40.
Filter 70 -> show score >= 70.

This gives one simple score control without weakening the Decision Engine.
