# v4.9.3 — Single Pair Source Cleanup

Cleanup only. Trading/decision logic is unchanged.

Changes:
- `config.js -> PAIRS` is now the only source of supported scanner pairs.
- Removed duplicated `SESSION_PAIR_POOL` from `server.js`.
- Session Ranking reads directly from `PAIRS`.
- `getAllSessionPairs()` also returns `PAIRS`.
- Added startup validation for duplicate or malformed pair symbols.
- Expanded `PAIRS` to include every pair already used by v4.9.2 Session Ranking.

Supported pair pool (17):
EUR/USD, GBP/USD, USD/JPY, USD/CHF, USD/CAD,
EUR/GBP, EUR/JPY, GBP/JPY,
AUD/USD, AUD/JPY, AUD/NZD,
NZD/USD, NZD/JPY,
EUR/CAD, GBP/CAD, AUD/CAD, CAD/JPY.

Preserved unchanged:
- normal score thresholds (52 / 54 / 55)
- Candle Confirmation Engine
- Decision Engine
- Telegram alerts
- Entry Zone / TOO LATE / WORST ENTRY protection
- MTF / SMC / expiration logic
- session ranking priorities and TOP-5 behavior
