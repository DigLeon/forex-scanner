# v5.2 Session-Off API Guard

- Shared REST Updater now stops completely during `ROLLOVER / SCANNER OFF`.
- The old dynamic pair universe is not polled while the scanner is off.
- Fast Recheck and pending-signal symbols cannot keep the shared updater alive during rollover.
- Candidate Discovery already had a rollover guard and remains disabled during scanner-off periods.
- Auto Scan may continue its lightweight scheduled session checks; with no active pairs it performs no market REST work.
- No scoring, entry, expiration, Telegram, TRADE, or WAIT>60 research logic was changed.
- No `.env` changes are required.
