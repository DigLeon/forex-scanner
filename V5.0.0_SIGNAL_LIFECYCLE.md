# Forex Scanner v5.0.0 — Signal Lifecycle

## Main changes

- READY is no longer terminal for Fast Recheck.
- A READY setup remains monitored every ~30 seconds.
- READY requests a strict one-pair priority full scan instead of waiting up to 10 minutes for Auto Scan.
- Final TRADE or invalidation/timeout closes the active lifecycle.
- Each watched setup receives a stable `setupId` propagated through WAIT / GET_READY / TRADE / paper logging.
- Signal Performance groups lifecycle events by `setupId` (legacy rows keep backward-compatible fallback behavior).
- GET READY is emitted once per active setup instead of every recheck.
- READY has a configurable short timeout (`FAST_RECHECK_READY_TIMEOUT_MS`, default 3 minutes); the general watch timeout remains in force.
- Paper Outcome horizons prefer the closed 1M candle at or immediately before the target timestamp when local history is available.
- Expiration result likewise prefers the 1M close at or before `expiryAtMs`; live sampling remains a marked fallback.
- Outcome rows now record target timestamp, price source, approximation flag and target delta.
- Auto Scan remains 10 minutes; WebSocket behavior is unchanged.

## Lifecycle

Auto Scan -> WAIT/Candidate -> Fast Recheck -> GET READY -> READY -> Priority one-pair strict scan -> TRADE or continued watch/SKIP -> Outcome Engine -> persistent statistics.
