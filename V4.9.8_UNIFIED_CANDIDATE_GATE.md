# v4.9.8 Unified Candidate Gate

This release removes the duplicate candidate threshold behavior.

Unified rule:
- score < 35 -> NO SIGNAL
- score 35 to below effective required score -> CANDIDATE / WAIT
- score >= effective required score -> normal signal pipeline
- candidate direction must match aligned Context + Setup
- candidates can never bypass final TRADE filters

Unchanged:
- effective TRADE floors 52 / 54 / 55
- Direction Edge requirements
- TOO LATE / WORST ENTRY
- Signal Strength rules
- Candle Confirmation
- v4.9.7 Direction Alignment penalty
- v4.9.6 Score Diagnostics
