# v4.12.1 Zone Identity Fix

Fixes false creation of new Zone IDs when the same structural FVG/imbalance
moves slightly between scans.

Matching rules:
1. Same symbol
2. Same direction
3. Same timeframe
4. Prefer structural zone overlap >= 45%
5. Otherwise allow Best Entry drift up to 1.5x the wider zone width
6. Very narrow FX zones get only a tiny absolute fallback tolerance

The Zone ID is now assigned once when a truly new zone is discovered.
Subsequent scans reuse the existing Zone ID when the structural zone still matches.

No trading thresholds or decision gates were changed.
