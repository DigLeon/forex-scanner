# v5.3.4.3 Signal Logger Diagnostics

This patch adds diagnostics only. Signal scoring, Entry Engine, expiration logic, Telegram thresholds, and execution gates are unchanged.

When a TRADE/WAIT record is not persisted, the console now prints `[SIGNAL LOGGER SKIP]` with a reason such as:

- `SCORE_BELOW_50`
- `NO_VALID_EXPIRATION`
- `NO_VALID_PRICE`
- `STALE_DATA`
- `INVALID_DIRECTION`
- `RECENT_DUPLICATE`

WAIT research records remain subject to the existing score >= 50, valid expiration, valid live price, and non-stale data rules.
