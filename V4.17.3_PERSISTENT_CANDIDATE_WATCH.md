# v4.17.3 Persistent Candidate Watch

Fast Recheck no longer treats `score < requiredScore` as an automatic terminal SKIP.

Rules:
- candidate score >= `candidateWatchFloor` (default 35): keep WATCH/WAIT if final gates are not ready;
- score >= requiredScore: may progress to GET_READY when the existing GET_READY gates pass;
- score < candidateWatchFloor: terminal SKIP/remove;
- direction change, Context/Setup conflict, TOO LATE, WORST/DO NOT ENTER, or NOT RECOMMENDED remain terminal blockers.

This preserves the strict final score threshold. It only changes how long an early candidate remains under REST Fast Recheck observation.

WebSocket behavior is unchanged. Auto Scan remains 10 minutes.
