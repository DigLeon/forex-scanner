# v5.1 — Dynamic Candidate Discovery Fix

- Candidate Discovery now uses the same latest dynamic active-pairs universe selected by the normal full scan.
- It no longer falls back to the static session Top-5 after a dynamic universe exists.
- Before the first dynamic scan selection, the existing session-ranked Top-5 remains the safe fallback.
- Shared REST Updater, Auto Scan, and Candidate Discovery therefore stay aligned on the current dynamic universe.
- No scoring, entry, expiration, Telegram, WAIT research, or signal-result logic was changed.
