# v4.8.1 Telegram Alerts

Add to .env:
TELEGRAM_ALERTS=true
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_chat_id

Automatic alerts are sent only for finalized TRADE.
CANDIDATE, WAIT and SKIP do not send Telegram alerts.
Duplicate protection uses symbol + direction + candleId + analysisId.
Use TEST TELEGRAM in GUI to verify the connection.
