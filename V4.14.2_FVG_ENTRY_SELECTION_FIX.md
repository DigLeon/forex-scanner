# v4.14.2 — FVG Entry Selection Fix

Entry Zone selection no longer ranks FVGs only by structural quality.

For entry timing, active same-direction FVGs are ranked with:
- entry-window viability first (not beyond Last/Worst),
- structural FVG quality,
- distance from current price in ATR,
- formation freshness.

If at least one viable FVG exists, an already-too-late FVG cannot beat it merely because it is a higher timeframe. If every active FVG is already late, the best remaining candidate is still returned so existing TOO LATE protection remains intact.

Signal score floors, edge floors, Candle Confirmation, Signal Strength, Telegram gating and WebSocket code are unchanged.
