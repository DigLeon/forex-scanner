# Forex Scanner v4.7.7 — WATCH weak setups

Added optional GUI checkbox:
Show WATCH 40+

Purpose:
- Let the user observe directional setups with score >= 40 that are still below the real pair/user trade threshold.
- Does NOT lower Minimum Signal Score.
- Does NOT change Effective Min Score.
- Does NOT convert weak setups into TRADE or WAIT.
- WATCH is research/observation only.

Server WATCH requirements:
- showWeak=1
- signal engine returned NO SIGNAL
- best directional score >= 40
- best directional score < required score
- directional edge still meets the pair's required edge

WATCH rows:
- action: WATCH
- reasonCode: WATCH_WEAK_SCORE
- entryQuality: WATCH ONLY
- no expiration is assigned
- no trade is logged

SKIP remains hidden in the main GUI.
