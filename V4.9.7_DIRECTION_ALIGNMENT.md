# v4.9.7 Direction Alignment

Two focused corrections:

1. Directional score penalty
- When Context and Setup are both aligned BULLISH, the DOWN score gets -30.
- When Context and Setup are both aligned BEARISH, the UP score gets -30.
- This prevents Entry/Strategy from overpowering two aligned higher layers.

2. Legacy weak-watch candidate
- `[SCAN CANDIDATE]` from `server.js` now requires Context + Setup alignment.
- Candidate direction must match the aligned Context/Setup direction.
- This prevents rows such as `EUR/GBP UP` while Context + Setup are BEARISH.

Unchanged:
- pair safety score floors 52 / 54 / 55
- candidate watch floor 35
- Direction Edge requirements
- TOO LATE / WORST ENTRY
- Candle Confirmation
- Signal Strength gates
- Score Diagnostics history
