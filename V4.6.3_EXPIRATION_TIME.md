# v4.6.3 Expiration Time

Expiration is now anchored to the close of the signal 1-minute candle.

Example:
- signal candle close: 10:00:00
- model horizon: 20 min
- REST / analysis ready: 10:00:45
- target expiry: 10:20:00
- remaining duration at analysis: 19m 15s

GUI shows the target clock time in Montreal instead of only the number of minutes.
The original model horizon is kept internally for statistics/research.
Paper signal logging now uses the same candle-anchored absolute expiry.
