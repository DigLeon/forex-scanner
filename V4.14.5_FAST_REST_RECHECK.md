# v4.14.5 — Fast REST Recheck

Adds a REST-only observational watchlist for directional WAIT setups.

- Full scan behavior is unchanged.
- WAIT setups are rechecked every 30 seconds by default.
- Only watched symbols are force-refreshed.
- Recheck logs score, Entry Zone, Signal Strength, and 1M/3M/5M candle confirmation.
- Terminal observational states are READY or SKIP.
- READY does not send Telegram and does not bypass the authoritative full-scan TRADE gate.
- WebSocket code is unchanged.
- Configure with FAST_RECHECK_INTERVAL_MS and FAST_RECHECK_MAX_AGE_MS if needed.
- GET /api/fast-recheck returns the current watchlist and latest observations.
