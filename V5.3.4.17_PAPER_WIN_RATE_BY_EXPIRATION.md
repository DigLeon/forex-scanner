# v5.3.4.17 — Paper Win Rate by Expiration

- Added dynamic `byExpiration` statistics to `/api/signal-stats` for completed TRADE paper records.
- Expiration values are discovered from `expirationMinutes`; no hardcoded list is used.
- GUI now shows `Paper Win Rate by Expiration` with WIN/LOSS/FLAT counts for each observed expiration (for example 20m, 22m, 23m).
- Win Rate = WIN / (WIN + LOSS); FLAT is shown separately and excluded from the percentage.
- Existing Overall Paper Win Rate remains unchanged.
- No changes to Score Engine, Entry Engine, direction, expiration selection, Telegram rules, or signal generation.
