# Forex Scanner v4.7.2 — primaryStrategy initialization fix

Fixed:
- `primaryStrategy` is now initialized BEFORE the EXECUTION GATE.
- WAIT / SKIP decision rows can safely read the strategy name.
- A valid SKIP such as `TOO LATE` will no longer turn into:
  `Cannot access 'primaryStrategy' before initialization`.

Trading logic, score, expiration calculation, Min Score filtering,
and the v4.7.1 Friendly GUI were not otherwise changed.
