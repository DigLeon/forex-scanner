# Forex Scanner v4.8.2 — Multiple Telegram Recipients

Use one bot and any number of chat IDs.

.env example:

TELEGRAM_ALERTS=true
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHAT_IDS=111111111,222222222,333333333

Each recipient must open the bot and press START first.

Behavior:
- Final TRADE is sent to every configured Chat ID.
- WAIT / CANDIDATE / SKIP are not sent.
- If one recipient fails, delivery continues to the others.
- Console logs individual Telegram recipient errors.
- Existing TELEGRAM_CHAT_ID is still accepted as a backward-compatible fallback.
