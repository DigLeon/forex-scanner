# v4.13.3 — Unified Structural FVG Zone ID

The FVG Birth Tracker and Entry Zone History now hash the same normalized
structural key:

`UPPERCASE_SYMBOL | DIRECTION | TIMEFRAME | FORMATION_DATETIME`

This fixes the case where the same USD/CAD UP 3M FVG formed at 14:03 produced
different IDs in the two trackers.

No scoring, pair safety floors, Entry Zone boundaries, TOO LATE rules,
confirmation logic, decision logic, or alerts were changed.

For a clean diagnostic run, runtime tracker state/history files are excluded
from this release ZIP so legacy IDs do not mix with the unified IDs.
