# v5.3.4.8 — Manual Analysis

Adds a separate `MANUAL ANALYSIS` tab to the GUI.

- Shows 10 current priority currency pairs.
- For each pair the user can select a 3, 5, or 15 minute research horizon.
- Each row has its own `SCAN` button.
- Uses the existing full analysis pipeline for the selected pair.
- The selected expiration is treated as a research horizon only; Score Engine, Entry Engine, direction logic, Telegram rules and automatic scanner logic are unchanged.
- GUI shows current decision/direction, score, Context, Setup, Entry, regime, and RSI metadata when present.
- Endpoint: `GET /api/manual-analysis/pairs`.
