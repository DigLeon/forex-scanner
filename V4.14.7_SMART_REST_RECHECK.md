# v4.14.7 Smart REST Recheck

- Fast Recheck remains automatic after a full Scan discovers WAIT setups.
- It no longer force-downloads 1500 1M candles every 30 seconds.
- Local 1M history is refreshed only when the existing ~60 second REST resync is due.
- Between history refreshes, the observer uses the lightweight current-price endpoint.
- 3M/5M analysis continues to be built locally from 1M history by the existing analysis pipeline.
- WebSocket behavior is unchanged.
- Final full-scan TRADE/Telegram authority is unchanged.
- Fast Recheck remains observational and never bypasses the normal decision gates.

Typical log:

    [SMART REST RECHECK] GBP/CAD | history: REUSED | price: PRICE_API
    [FAST RECHECK] GBP/CAD UP | state: WAIT ...

When the normal history refresh becomes due:

    [LOCAL HISTORY] GBP/CAD REST BOOTSTRAP
    [SMART REST RECHECK] GBP/CAD | history: REFRESHED | price: PRICE_API
