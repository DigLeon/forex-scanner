# v4.14 — Event-Driven Market Monitor

Purpose:
- Keep REST for historical data and heavy multi-timeframe analysis.
- Add realtime event hooks for price updates and closed 1M candles.
- Re-evaluate the currently known Entry Zone immediately between full scans.
- Do not change Score floors, Entry Zone boundaries, TOO LATE, Candle Confirmation,
  final decision rules, or alert behavior.

Realtime decision logic:
- TOO LATE => SKIP
- GOOD ENTRY + Strength >= 50 + Candle Confirmation confirmed => TRADE
- otherwise => WAIT

Important:
- This module does not create a setup from ticks.
- It only monitors setups already created by the normal scanner.
- If Twelve Data WebSocket is unavailable on the current plan, REST remains primary and
  the event hooks stay idle until a realtime source emits events.
