# v4.13.4 — Canonical FVG ID

A single `makeCanonicalFvgId()` in `smc.js` now owns structural FVG identity.
Both FVG Birth Tracker and Entry Zone History call that same function using:
symbol + direction + timeframe + formationDatetime.

This removes independent structural hash implementations.

No Score thresholds/weights, Entry Zone boundaries, TOO LATE rules,
Candle Confirmation, final decision logic, or alert behavior were changed.
