# v5.3.4.6 Analysis Audit / Prediction Lock

- Adds `analysisAuditLogger.js` and `analysis-audit-history.json` (created on first scan).
- Stores every fully analyzed pair, including WAIT/SKIP as standardized research `decision: WAIT`; original action is preserved in `rawDecision`.
- Adds immutable prediction metadata: analysisId, batchId, versions, predictionLocked, predictionLockedAt, snapshotHash/inputDataId.
- Fixed research horizons: 3, 5, 10, 15, 20, 22, 25, 30 minutes.
- Outcome selection no longer silently uses a 1m candle closing before target time. It uses the first available close at/after target, or an explicitly approximate live sample.
- Stores target/observed timestamps, delta, validity and invalidReason.
- Existing `signal-history.json` remains the WAIT/TRADE >50 operational research stream.
- No Score Engine, Entry Engine, direction, Telegram or expiration-generation rules were changed.
