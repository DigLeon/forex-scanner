# v4.15 — REST Credit Manager

- Adds a global Twelve Data REST request gate in `marketData.js`.
- Default budget: 7 actual outbound HTTP attempts per rolling 60 seconds (provider log showed 8/min; one credit is reserved as headroom).
- Cache hits and coalesced reads do not consume the local manager budget.
- Full Scan and Smart REST Recheck share the same budget, so rechecks queue instead of bursting into HTTP 429.
- Retries also pass through the same gate.
- Configure with `TWELVE_REST_CREDITS_PER_MINUTE` (1..8). Default is 7.
- No WebSocket changes. No Score/FVG/Entry Zone/Strength/Candle/Telegram rule changes.
- GUI polling remains local and does not consume Twelve Data credits.
