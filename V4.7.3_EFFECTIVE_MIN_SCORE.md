# Forex Scanner v4.7.3 — Effective Minimum Signal Score

The GUI Minimum Signal Score now participates in the actual scanner decision,
not only in post-request display filtering.

Formula:

Effective Min Score = max(User Min Score, Pair Safety Minimum)

Examples:

- GUI = 50, USD/CAD pair safety floor = 54
  -> effective minimum = 54

- GUI = 70, USD/CAD pair safety floor = 54
  -> effective minimum = 70

This preserves pair-specific safety floors while allowing the user to make
the scanner stricter from the interface.

Implementation:
- GUI sends `/api/scan?minScore=50|60|70|80`
- server validates the value
- server passes `userMinScore` to `combinedAnalysis()`
- analysisEngine calculates the effective minimum before candidate selection
- `signalDiagnostics.requiredScore` now contains the effective minimum
- `signalDiagnostics` also exposes pairSafetyMinScore, userMinScore,
  effectiveMinScore
- final results expose `scoreThreshold`

The GUI still applies the same selected score as a display safety filter,
but the key change is that the selected minimum is now enforced inside
the actual analysis engine.
