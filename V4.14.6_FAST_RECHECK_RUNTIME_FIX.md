# v4.14.6 — Fast Recheck Runtime Fix

REST-only diagnostic/runtime fix. WebSocket behavior is unchanged.

- Logs `[FAST RECHECK WATCH]` whenever a WAIT setup is registered.
- Logs `[FAST RECHECK TIMER]` when the timer runs or is skipped by a full scan.
- Schedules an immediate 1-second post-scan recheck when the watchlist is non-empty, so a long full scan cannot consume the 30-second timer opportunity.
- Existing 30-second interval remains as a fallback.
- Fast Recheck remains observational: it does not send Telegram and does not bypass the authoritative full-scan decision gate.
- Score floors, Candle Confirmation, FVG selection, Entry Zone, Signal Strength, Telegram gate, and WebSocket behavior are unchanged.
