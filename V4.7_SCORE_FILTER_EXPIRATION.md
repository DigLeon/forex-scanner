# Forex Scanner v4.7 — Score Calibration & Display Controls

## Score calibration

The market score was changed from:
- Context 30%
- Setup 35%
- Strategy 20%
- Session 15%
- Entry 0%

to:
- Context 20%
- Setup 30%
- Entry 25%
- Strategy 15%
- Session 10%

The final directional score also receives explicit quality adjustments:
- +5 aligned context + setup in the analyzed direction
- -5 neutral HTF context
- -9 neutral setup
- +5 strong aligned entry layer
- -10 opposing entry layer
- -5 weak entry layer
- -20 direct context/setup conflict
- regime penalties: Low Volatility -6, Range -5, High Volatility -2

Hard TRADE/WAIT/SKIP rules remain separate in Decision Engine.

## Minimum Score display filter

GUI selector:
50 / 60 / 70 / 80

This is DISPLAY filtering only.
The scanner still analyzes and logs all decisions so research/statistics remain complete.

Directional UP/DOWN rows below the selected score are hidden.
NO SIGNAL / ERROR diagnostic rows remain visible.

Preference is saved in browser localStorage.

## Expiration display

GUI selector:
- Clock Time
- Minutes

Clock Time displays the candle-anchored Montreal target time.
Minutes displays the remaining duration to the same absolute target.

No expiration calculation is changed by this selector; it only changes presentation.
