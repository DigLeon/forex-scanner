# v4.12 Persistent Zone History

Persistent structural Entry Zone memory with stable Zone ID.

Tracks across scans:
- firstSeenAt / lastSeenAt
- first snapshot and closest snapshot to Best Entry
- first IN ZONE
- first PRE-OPPORTUNITY
- first OPPORTUNITY
- first CANDIDATE
- first CONFIRMED
- final state: CONFIRMED IN TIME / CONFIRMED TOO LATE / MISSED BEFORE CONFIRMATION

Runtime files:
- entry-zone-state.json
- entry-zone-history.jsonl

API:
- GET /api/entry-zones
- GET /api/entry-zone-history
- POST /api/entry-zone-history/clear

Observational only. It does not create TRADE and does not weaken any existing gates.
