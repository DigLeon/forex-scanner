# v5.3.4.10 Manual Paper Timer + Statistics

- Manual Analysis remains PAPER/RESEARCH only.
- Each directional manual scan schedules a paper evaluation at the next 1-minute candle boundary.
- GUI shows a second-by-second countdown to that boundary and then to the selected 3/5/15 minute result horizon.
- Every manual paper observation is persisted in `manual-analysis-history.json`.
- Results are automatically updated from the existing shared realtime/local-candle outcome flow; no additional Twelve Data REST request is required.
- Manual Analysis screen shows total records, WIN, LOSS, FLAT, pending count, win rate, and 3m/5m/15m breakdown.
- Core Score Engine, Entry Engine, Auto Scanner, Telegram rules and normal signal-history logic are unchanged.
