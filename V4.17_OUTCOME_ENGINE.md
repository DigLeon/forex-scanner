# v4.17 — Persistent PAPER Outcome Engine

Adds automatic PAPER outcome tracking without changing the trading decision gates.

- Samples every pending signal approximately once per minute while the server is running.
- Reuses Fast Recheck prices when available; otherwise uses the existing REST `/price` path through the REST Credit Manager.
- Stores comparable 3m / 5m / 10m / 15m outcomes (plus existing research/expiration horizons).
- Outcome classes: WIN / LOSS / FLAT / INCOMPLETE. Default FLAT tolerance is 0.5 bps (`OUTCOME_FLAT_BPS`).
- Tracks sampled MFE and MAE in basis points for each PAPER signal.
- Persists results in `signal-history.json`, so ordinary server restarts do not erase collected statistics.
- `/api/signal-stats` now includes per-horizon win rates and aggregate sampled MFE/MAE.
- Existing Score, FVG, Entry Zone, Candle Confirmation, Telegram gates, WebSocket behavior and REST Credit Manager are unchanged.

Important: MFE/MAE are sampled approximations, not tick-perfect extrema. If the server is offline, intermediate movement cannot be observed by this engine.
