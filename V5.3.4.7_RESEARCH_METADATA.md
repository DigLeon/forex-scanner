# v5.3.4.7 Research Metadata

Adds diagnostic-only snapshots to every new WAIT/TRADE signal record:

- RSI(14): 1M, 5M, 15M
- ATR(14): 1M, 5M, 15M
- ATR %: 1M, 5M, 15M
- MACD: 5M line, signal, histogram
- distanceToBestEntryAtr
- nested researchMetadata snapshot with capture time and supporting diagnostics

The snapshot is computed from the already-loaded local closed 1M history and local 5M/15M aggregation. It makes no extra Twelve Data REST request and does not alter Signal Score, Entry Engine, direction, expiration, Telegram filters, or execution decisions.

The package also includes the merged signal-history.json containing the preserved Sep 1-3 research history. Historical records created before this version keep null/missing RSI fields because those values were not captured at signal time.
