# v5.0.3 — Candidate Discovery

- Full Auto Scan remains every 10 minutes.
- New lightweight Candidate Discovery runs every 2 minutes after Auto Scan is armed.
- It refreshes only the top 5 session-ranked pairs with a small 1M REST window (default 180 candles).
- It runs Adaptive Prefilter only. It cannot create TRADE/WAIT/GET_READY by itself.
- Promising new candidates (priority score >=45 by default) request the existing strict single-pair Priority Scan.
- Existing Fast Recheck continues about every 30 seconds for already discovered candidates.
- REST Credit Manager remains authoritative for all outbound Twelve Data requests.
- Per-symbol discovery priority requests have a 5-minute cooldown.
- WebSocket behavior is unchanged.

Environment overrides:
- CANDIDATE_DISCOVERY_INTERVAL_MS (minimum 120000)
- CANDIDATE_DISCOVERY_REFRESH_OUTPUTSIZE (120..300, default 180)
- CANDIDATE_DISCOVERY_PREFILTER_MIN (default 45)
- CANDIDATE_DISCOVERY_PAIR_LIMIT (1..5, default 5)
- CANDIDATE_DISCOVERY_PRIORITY_COOLDOWN_MS (minimum 120000, default 300000)
