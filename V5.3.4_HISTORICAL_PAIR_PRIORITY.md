Research-mode ranking change only.

- USD/JPY: +10
- AUD/JPY: +7
- AUD/CAD: +5
- EUR/GBP: -5
- all other pairs: 0

The bonus is added to `priorityScore` after the live adaptive prefilter is calculated. The original `prefilterScore` is preserved. This means current market quality remains the main ranking input while historical performance can break or influence close rankings.

The bonus affects only which pairs receive priority inside the Top-10 full-scan/candidate universe. It does NOT modify Signal Score, Entry Score, direction, expiration, candle confirmation, Telegram threshold, or TRADE/WAIT execution gates.

Candidate Discovery uses the same historical bonus, so ranking is consistent with the normal full scan.
